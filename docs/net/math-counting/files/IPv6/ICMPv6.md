## 一、ICMPv6 概述
```
	作用：
        用于在 IPv6 网络中传递差错信息，控制信息（如：网络不可达、TTL 超时等，NDP 协议等）

	0—127 为：
        差错信息（如：目的不可达、TTL 超时、包过大等）
	
    128—255 为：
        控制信息（如：邻居发现、无状态自动配置、组播发现协议等）
```
### 1、通过 ICMPv6 的差错信息（type=2 返回的 PMTU 值来确保源设备发出的数据包大小）
```
	运行 PMTU 后，源设备到达目的设备的 MTU 值都会进行检测（最终使用 PMTU 最小值来封装数据包和发送，减少中段分配问题，只在数据源做分配，减少重传）
```
### 2、NDP 协议
#### NS 和 NA 可以实现以下的功能
```
① 地址解析：
    使用 NS 和 NA 报文
        来获取以太网接口的 IPv6 地址和 MAC 地址的映射关系（类似于 IPv4 的 ARP 地址解析）

② 邻居状态跟踪：
    使用 NS 和 NA 请求对端设备接口的 MAC 地址时，
        IPv6 设备根据交互报文的情况跟踪邻居状态，形成邻居跟踪表

③ 重复地址检测：
    当配置了单播地址后，会主动向该地址的被请求节点组地址发起 DAD 检测
		如果有回复，则该地址不可用（地址冲突）
		如果没有回复，则改地址可用
```

#### RS 和 RA 可以实现以下功能
```
① 路由器发现：
    终端或者网络设备可以主动通过链路本地地址发送 RS 报文（用于发现所连接的路由设备）

② 前缀通告（无状态自动配置）：
    当路由器收到 RS 报文后，如果接口关闭了 RA 抑制功能，即可响应回复 RA 报文
				RA（可以携带路由前缀信息，一般不超过 64 bit）
				也能周期性主动发送 RA 报文，用于给接入终端分配 IP 地址
————————————————————————————————————————————————
③ 无状态自动配置：
    终端设备可以通过 RA 分配的前缀 + 接口 MAC 地址（EUI-64）生成 IPv6 地址
```

##### 无状态自动配置：
```
	只分配 IPv6 地址前缀，无法分配完整的 IPv6 地址，
    无法携带选项信息（option 43“AC 的管理地址”、DNS 服务信息等）
	    优点：
            轻量级的地址分配方式，可以实现设备接入即可获取 IPv6 地址，实现网络通信
	    缺点：
            无法跨越链路传递，无法携带选项信息
```
##### 有状态自动配置：
```
	通过 DHCPv6 服务器获取完整的 IPv6 地址，
    选项信息（如：option 字段、服务器 ID、DNS 信息等）
	同时服务器能够感知用户的状态（如：是否在线、是否需要释放地址、续约等）
	
        优点：
            可以携带选项信息，可以跨越广播域（如：配置 DHCPv6 中继）
	    缺点：
            需要部署和维护 DHCPv6 服务器
```
```
RA 报文中的 flags 位可以控制接入终端使用哪种方式获取地址和选项信息

    M=0 代表使用 RA 报文的前缀配置 IPv6 地址
    M=1 代表使用 DHCPv6 服务器获取前缀，    
        配置 IPv6 地址（M=1 时，自动忽略 O bit位，所有的信息都由 DHCPv6 服务器获取）

    O=0 代表使用 RA 获取选项信息（如：前缀以外的 MTU、时间等）
    O=1 代表使用 DHCPv6 服务器获取选项信息（如：DNS、时间、服务器 ID 等）
    （缺省情况下都为 0，都由 RA 获取）
```



## 无状态自动配置 配置
```
路由器侧
1、开启 IPv6 协议栈
	ipv6

2、进入接口配置 IPv6 地址及设置 RA 信息 
	interface G0/0/X
	ipv6 enable 
 	ipv6 address 2000::2/64 			// 进入 G0/0/X 接口，使能 IPv6 及配置全球单播地址

3、关闭 RA 抑制功能
	interface G0/0/X
 	undo ipv6 nd ra halt				// 关闭 RA 抑制后，该接口会主动发送 RA 报文（并携带接口全球单播地址的前缀信息）
							（2000::/64）
4、（可选）指定 RA 的前缀
	interface G0/0/X
	ipv6 nd ra prefix 3000::/64 3600 1800 		// 指定 RA 分配的前缀为 3000::/64  使用时长 3600s，续约时长 1800s

主机侧（使用路由器模拟）
1、开启 IPv6 协议栈
	ipv6

2、进入接口配置 IPv6 地址及设置 RA 信息 
	interface G0/0/X
	ipv6 enable 
 	ipv6 address auto global			// 使用 RS 获取 RA 信息并自动生成 IPv6 全球单播地址

3、查看方式
	display ipv6 interface G0/0/X			// 查看接口详细 IPv6 信息
```


## 有状态自动配置（DHCPv6）配置
```
服务器侧
1、开启 IPv6 协议栈
	ipv6

2、进入接口配置 IPv6 地址及设置 RA 信息 
	interface G0/0/X
	ipv6 enable  
 	ipv6 address 3000::2/64 			// 配置接口 IPv6 全球单播地址（用于接口通信）

3、开启 DHCP 服务及创建地址池
	dhcp enable

	dhcpv6 pool PC1					// 创建地址池 PC1
 	address prefix 3000::/64			// 配置地址池范围：3000::/64 

4、调用地址池
	interface G0/0/X
	dhcpv6 server PC1				// 调用地址池名称：PC1
	
主机侧
	点击 DHCPv6，右下角应用即可
	查看 ipconfig 即可
```
