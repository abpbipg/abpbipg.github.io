## 一、IPv6 地址
```
	IPv6 地址 16bit 为一段，划分为 8 段，使用 ：来进行连接

	（0001 可以缩写为 1，0101 可以缩写为 101）
	（2 段及以上的 0000 可以缩减为 ::，但 :: 在一个 IPv6 地址中只能使用 1 次）

	例如：
        2000:0000:0000:0001:0000:0000:1202:0011  
    可以写为   
        2000:0:0:1::1202:11 
     或 2000::1:0:0:1202:11
```

### 1、单播地址：
#### ① 全球单播地址：用于全球范围通信，类似于 IPv4 的公网地址
```
		固定前缀 001（3bit）+ 前缀地址（45bit）+ 子网 ID（16bit）+ 接口 ID（64bit）
		全球单播地址范围：2000—3FFF/3bit
		例如：2000::1/64、2000:12::1/64

		补充：一个 IPv6 接口能够支持 N 个全球单播地址（均能用于通信）IPv6 接口中的全球单播地址不是必须存在
```	

#### ② 链路本地地址：仅在链路范围通信（接口范围）可以应用于无状态自动配置、邻居发现协议、OSPFv3 邻居建立的源等地址
```
		固定前缀 FE80（10bit）+ 固定 0（54bit）+ 接口 ID（64bit）
		固定格式 FE80::/10	例如：FE80::1
		一般前 64 bit 为 FE80:: 后 64 bit 接口 ID 自动生成（也能手工指定）
```	
##### 补充：自动生成方式
```
	1、软件生成（如：操作系统，通过伪随机算法生成）
	2、EUI-64 生成（利用接口的 MAC 地址 + FFFE 字段生成）

	补充：EUI-64 是把 MAC 地址生成为 64 bit 接口 ID 的技术
		① 如：MAC 地址 = 0011-2222-3333
		② MAC 地址会分为前 24 bit 和后 24 bit，0011-22  /  22-3333
		③ 中间插入 FFFE（16 bit 的字段），0011-22FF-FE22-3333
		④ 把第 7 bit 取反，代表全球唯一；       00 = 0000 0000 取反后（0000 0010）= 02
		⑤ 211:22FF:FE22:3333 生成的链路本地地址为：FE80::211:22FF:FE22:3333
		
	手工配置
		ipv6 address FE80::1 link-local			// 指定接口的链路本地地址为：FE80::1

		补充：一个 IPv6 接口必须有链路本地地址（有且只能有一个）用于 IPv6 的即插即用
```

#### ③ 唯一本地地址：用于内部网络通信，不在运营商路由，类似于 IPv4 的私网地址
```
		固定前缀：FC00::/7	1111 110X	当 X=0（FC00::/8）	当 X=1（FD00::/8）
		目前唯一本地地址使用的范围是： FD00::/8
		固定前缀（8bit）+ 全球随机标识（40bit）+ 子网 ID（16bit）+ 接口ID（64bit）
```

#### ④ 特殊单播地址：有固定意义无法分配给个人或机构使用的 IPv6 地址
```
		::1/128	 环回接口地址，类似于 IPv4 的 127.0.0.1/32
		::/0     缺省路由          类似于 IPv4 的 0.0.0.0/0	（未指定地址）
```

### 2、组播地址：用于标识一组设备或接口的 IPv6 地址
```
	固定前缀 FF（8bit）+ （标识位）4bit + 范围位（4bit）组成头部 + （80bit 0 或填充信息）+ 组播 ID（32bit）
	标识位 = 0 代表永久组播，有固定意义的组播 IPv6 地址		
	标识位 = 1 代表临时组播，没有固定意义的，可以分配给用户使用的组播地址

	范围位
    	01 本地使用、
        02 链路使用

	例如：
        FF02 代表永久组播地址，链路范围传递
	
    FF02::1		// 所有网络节点组地址。类似于 IPv4 224.0.0.1
	FF02::2		// 所有路由器节点组地址。类似于 IPv4 的 224.0.0.2
	FF02::5		// OSPFv3 使用的组播地址。类似于 IPv4 的 224.0.0.5
	FF02::D		// PIM 协议使用的组播地址。类似于 IPv4 的 224.0.0.13
```
#### 临时组播地址
```
	FF12::1		// 代表组播组为：FF12::1

	组播 MAC 地址固定格式：3333-XXXX-XXXX（后 32bit 为组播 ID）


	被请求节点组地址：只要配置了单播地址，都会主动加入到被请求节点组，后 24 bit 由单播地址映射
	（用于邻居发现协议，如：地址解析、地址冲突检测等）
	FF02::1:FF00/104		例如：配置单播地址为：  2000::1234:1234/64   加入的组为：FF02::1:FF34:1234

	只要后 24bit 一致的 IPv6 单播地址，都会加入到同一个被请求节点组
```

### 3、任播地址（anycast）任播地址一般标识一组设备或接口，与全球单播地址使用相同的地址空间（不会冲突，不会进行 DAD 检测）
```
		可以为多个不同的服务器配置相同的任播地址，从而实现移动 IPv6 特性
		当目标地址是任播地址的数据包将发送给其中路由意义上最近的一个网络接口
```

## 二、IPv6 报文格式
```
	简化了头部字段，固定头部大小为 40 字节
	流量匹配：使用头部的流标签 + 源 IPv6 地址即可唯一确定一条流量
```

## 三、IPv6 相比于 IPv4
```
1、海量的地址空间（2 的 128 次方）
2、简化了 QOS 的流量分类
3、实现即插即用（无状态自动配置）引用了链路本地地址，实现 IPv6 设备接入后就能获取地址和链路通信
4、简化了 IPv6 头部字段
5、IPv6 地址分层，划分子网等更加清晰
6、IPv6 取消了广播（安全性和扩展范围得到控制）
```
