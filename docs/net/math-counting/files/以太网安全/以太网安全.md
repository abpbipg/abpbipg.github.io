# 以太网安全
## 一、MAC 地址表
### 1、静态 MAC
```
	由管理员手工配置指定的 MAC 地址记录关系（信息：MAC 地址、接口 ID、VLAN ID）静态绑定后不会被其他接口刷新
	作用：防止攻击者伪冒合法用户的 MAC 地址和端口记录关系欺骗合法设备

	静态 MAC 地址：不会因为接口的热插拔、系统复位、接口 up/down 和时间等老化
	长用于固定位置的终端设备使用（如：服务器、打印机、摄像头等）
```

### 2、动态 MAC
```
	交换设备会根数据包的源 MAC 地址进行学习，记录源 MAC 地址和接口的对应关系，老化时间 300s
	
	当相同 VLAN 不同接口收到相同的源 MAC 地址，后学习的 MAC 地址会覆盖前面的信息
	同时也会收到接口热插拔、系统复位等影响，自然老化
	（可以减少未知单播帧的泛洪）
```

### 3、黑洞 MAC
```
	如果在交换设备中收到恶意用户大量的攻击报文（如：DDOS 攻击）消耗设备资源
	管理员可以手工把 MAC 地址和 VLAN 绑定到黑洞 MAC 中，收到该数据帧（无论时源或者目的 MAC 被匹配，都会丢弃该数据包，防止 DDOS 攻击）
```

## 二、端口安全
```
	根据 MAC 地址表的记录关系进行安全防范
	当收到的数据帧（源 MAC 地址）与接收接口的 MAC 地址表不一致，则丢弃数据帧（或者关闭端口）
```
### 1、静态端口安全：
```
    管理员手工把 MAC 地址绑定到端口上
			优点：
                MAC 地址记录不会因为端口 up/down、端口热拔插、系统复位等丢失
			缺点：
                难以管理（收集 MAC 困难）
			适用于：
                不经常移动位置的终端配置（如：服务器、打印机、固定办公终端等）
```
### 2、动态端口安全：
```
    根据接收到的数据帧（源 MAC 地址）进行学习（缺省情况下，接口学习数量为 1）
			优点：
                适合于移动办公的员工
			缺点：
                表项会老化，重启设备或端口热插拔等都会老化
```

###	3、sticky 端口安全：
```
    可以把动态端口安全学习到的 MAC 地址，转为不老化
			优点：
                与静态端口安全一致，可以实现表项的不老化
```

#### 	配置命令：
```
	interface G0/0/X
	port-security enable				// 进入 G0/0/X 接口，开启端口安全功能
							（开启后，缺省为动态端口安全，只学习 1 个用户 MAC）

	port-security max-mac-num 5			// 把端口的 MAC 地址学习数量调整为 5 个


 	port-security protect-action shutdown		// 保护动作（当收到非法数据帧时，关闭端口）
							缺省：丢失非法数据帧，并告警

 	port-security mac-address sticky		// 把动态端口安全记录的 MAC 地址转为 sticky		
```


## 三、MAC 地址漂移、广播风暴
```
环路会导致广播风暴（大量的广播数据帧、未知单播帧在交换网络中无休止的泛洪）
	① 设备 CPU、内存利用率过高，导致设备宕机
	② 频繁刷新 MAC 地址表项
	③ 占用链路带宽
```

## 四、DHCP snooping
```	
    通过终端和服务器交互 DHCP 报文实现防欺骗、地址耗尽等攻击的作用
	
    1、信任功能：开启 DHCP snooping 后，交换设备所有的端口都设置为非信任端口（不处理：服务器报文“offer、ACK、NAK”）
			可以手工打开信任服务器的端口，配置为 trust，使其可以处理服务器报文
			作用：可以防范 DHCP 伪冒服务器攻击

	2、监听功能：通过客户和服务器交互的信息，生成 DHCP snooping 绑定表（最终收到 ACK 报文后才会生成表项）
			表项信息（如：端口 ID、IP 地址、MAC 地址、VLAN ID、时间）
			（结合 DAI 防范中间人攻击、结合 IPSG 防范源欺骗攻击）

	3、其他防范内容
		DHCP 服务器饿死攻击，通过修改 CHADDR 值（MAC 地址）恶意请求 DHCP 服务器的 IP 地址
		导致地址池耗尽，无法为合法用户提供服务

		① 开启 CHADDR 检测机制，可以检测 discover 报文中的 CHADDR 字段和二层头部的源 MAC 地址是否一致
			如果一致则转发该报文，否则丢弃（避免攻击者修改 CHADDR 字段恶意获取 DHCP 服务器地址）

		② 开启接口或者 VLAN 的用户接入数量
			如：G0/0/1 接口，开启最大支持用户数量为 10，超过 10 个请求成功的 IP 地址，则不再分配新的 IP
```

## 五、URPF（单播反向转发检测）
```	
    1、严格模式：
        转发的数据包源 IP 地址必须在路由表存在，且出接口与接收流量的接口一致，才能转发数据包
	2、松散模式：
        转发的数据包源 IP 地址必须存在于路由表，才能转发


	（ARP 攻击、源 IP 欺骗、DHCP snooping）
```
