# 防火墙基础
## 概念
### 1、安全区域：用于隔离访问，默认有 4 个区域，无法修改优先级也无法删除
```
    ① trust（信任区域）优先级：85
    ② untrust（非信任区域）优先级：5
    ③ DMZ（隔离区域）优先级：50
    ④ local（本地区域）优先级：100
如：根据优先级进行访问（高优先级能够访问低优先级，反之禁止）

安全区域也支持自定义配置（自定义区域可以创建、修改和删除）
```

### 2、安全策略
```
    默认情况下不同区域的设备无法实现访问，必须通过安全策略
    （通过多个 rule “规则” 组合，实现用户的行为和访问控制）
```

## 配置命令
```
1、把接口划入安全区域
	firewall zone trust				// 进入信任区域
	firewall zone name web				// 进入自定义区域（web）

	add interface G1/0/0				// 把 G1/0/0 划入某个区域（如：trust）
	（缺省情况下，相同区域的设备能够实现互访）

2、不同区域的设备需要通过安全策略
	安全策略配置
	 rule name PC-Internet				// 规则名称：PC-Internet
  	source-zone trust				// 源区域为：trust
  	destination-zone untrust			// 目的区域为：untrust
  	action permit					// 动作：允许
	（允许 trust 区域的设备访问 untrust 区域的设备）


 	rule name web							// 规则名称：web
  	destination-zone web						// 目的区域为：web
  	source-address 100.1.1.1 mask 255.255.255.255			// 源地址为：100.1.1.1/32
  	service http							// 协议类型
  	service https	
  	action permit							// 动作：允许
	（允许 100.1.1.1 访问 web 区域的设备，仅允许 http 和 https 应用通过）

3、进入接口配置 IP 地址及方向服务类型
	interface G0/0/X
	ip address X.X.X.X  24					
	service-manage http permit
 	service-manage https permit					// 进入 G0/0/X 接口配置 IP 地址，及防行访问的服务类型

（补充：默认情况下 FW 只允许 HTTP 登录和 SSH 登录）
账号：admin
密码：Admin@123 （第一次登录后，修改密码：Huawei@123）
```
```
补充：（HTTPS 登录  “web 登录”）
1、本地电脑添加 TEST 环回接口网卡
	（设备管理器）
		↓
	网络适配器
		↓（左上角）操作→添加过时硬件
					↓ 手动安装（找到网络适配器，选择微软的网卡，找到 TEST 环回接口）
2、创建网卡后，进入网卡配置 IP 地址即可

3、桥接网卡
	ENSP 创建 cloud（桥接网卡）
		添加网卡（如果没有发现新安装的网卡，则重启电脑）

	在添加 UDP 接口网卡
		把 1 和 2 绑定（双向通道）增加即可出现 UDP 接口
	
	UDP 接口连接防火墙

4、防火墙配置
	interface GX/X/X
 	ip address X.X.X.X 24			// 配置与本地电脑相同网段的 IP 地址
 	service-manage http permit
 	service-manage https permit		// HTTP 和 HTTPS 用于 web 连接
 	service-manage telnet permit		// 用于 Telnet 连接
	service-manage ping permit		// 用于测试是否能够访问防火墙

5、把 GX/X/X 接口划入安全区域
	firewall zone name web				// 进入自定义区域（web）
	add interface GX/X/X				// 把 G1/0/0 划入某个区域（如：web）		

	rule name web							// 规则名称：web
  	destination-zone web						// 目的区域为：web
  	source-address X.X.X.X mask 255.255.255.255			// 源地址为：X.X.X.X（本地电脑 IP 地址）
  	service http							// 协议类型
  	service https	
  	action permit							// 动作：允许
```

## Telnet
```
本地登录（Telnet）
1、防火墙创建登录账户
	aaa								// 进入 AAA 视图，创建用户账户
	manager-user A
  	password cipher Huawei@123
  	service-type web telnet ssh
  	level 15

2、开启 Telnet 服务，设置登录协议类型
	telnet server enable 						// 系统配置视图

3、进入 VTY 0 4 信道
	user-interface vty  0 4
	protocol inbound all						// 允许 Telnet 和 SSH 登录

4、使用本地的 CMD 登录即可
	telnet + FW IP 地址
```
