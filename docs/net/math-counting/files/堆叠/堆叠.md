# istack（智能堆叠）
```
    适用于盒式交换机（X7 系列的园区交互设备）
```

## 1、角色
```
    主交换机（master）在一个堆叠系统中，有且只能有一台主交换机
        （充当主控板的作用，所有的配置信息都由主交换机完成）
    
    备交换机（standby）在一个堆叠系统中，有且只能有一台备交换机
        （与主交换机同步配置信息，如：IP 地址、VLAN、MAC 表项等）
		  
        一旦主交换机故障，则备份交互设备会主动充当新的主交互机，接替原有的业务

    从交换机（slave）在一个堆叠系统中，可以存在 N 态从交换机，用于接收主交换机下发的流表信息，执行数据转发
		
        类似于框式交互机中的接口卡（接口板）
```

## 2、堆叠接口
```
    ① 堆叠卡堆叠：
        使用专门的堆叠接口卡来完成连接（不占用业务接口资源）
    
    ② 业务口堆叠：
        使用转发接口充当堆叠接口来使用（如：G0/0/1）
```

### 连接方式
```
1. 链状堆叠：把设备堆叠接口连成一条直线
		优点：
            适合传输距离较远的堆叠
		确定：
            没有冗余性，一旦堆叠链路或接口故障，会导致堆叠分裂

2. 环状堆叠：把设备连成环装，设备首尾相连
		优点：
            有冗余性，单设备或链路、接口故障只会导致堆叠变为链状堆叠，不会堆叠分裂
		缺点：
            传输距离可能受首尾相连设备的距离限制
```

## 3、堆叠 ID（Slot ID）
```
	用于识别成员设备，也可以替代槽位号
	如：
        Slave 成员 1 的接口为：G0/0/1，分配的 Slot ID 为：1	则该端口会替换为：G1/0/1
```

## 4、堆叠选举规则
```
	1. 先运行超过 20s 的设备首先进入堆叠系统
	2. 双方设备运行均不超过 20s，
        则根据优先级进行比较（数值越高越优，缺省为：100）
	3. 优先级一致，则比较 MAC 地址（越小越优）
```

## 5、工作方式
```
1. 成员加入：
    成员配置好堆叠信息后，保存并接入堆叠系统即可
    （成员设备会重启，并加入到堆叠系统）
    
    主交换机会给新加入的成员分配堆叠 ID，并更新拓扑信息

2. 堆叠合并：
    如果存在两套堆叠系统合并，双方的主交换机会进行竞选
    
    失败的一方会重启整个堆叠系统的交互设备，以从的身份接入
    （重启设备并同步拓扑信息）

3. 成员退出：

    从设备退出，
        主设备会更新拓扑信息（并把拓扑信息下发给堆叠系统中的其他成员，如：接口信息、流表信息等）
    
    备设备退出，
        主设备会从剩余的从设备中选出新的备设备，更新拓扑并同步配置信息给备设备

    主设备退出（堆叠分裂）
        主设备退出时（如果主设备还能正常工作，堆叠线缆故障）会导致出现两个堆叠系统
    
    主1（原为主设备）形成新的堆叠系统1，主2（备份设备升级为主）形成新的堆叠系统2，两个堆叠系统都保留原有的配置信息
    （如：IP 地址、MAC 地址、VLAN 等，导致上行和下行设备发现 IP 地址和 MAC 地址等信息冲突问题）

    可以在堆叠系统中运行 MAD 协议，并配置相关传输线缆，实现堆叠系统的检测

    MAD 检测
        会周期性 30s 发送 MAD 检测报文，检测堆叠系统是否分裂（如果发生分裂，则每隔 1s 发生一次堆叠分裂报文）
    
        两个分裂的堆叠系统会进行选举
    
    （最优的堆叠系统继续转发用户数据，比较失败的堆叠系统会关闭所有的业务接口 “保留堆叠接口和 MAD 接口”）
    
    （当堆叠系统恢复后，比较失败的堆叠系统会重新以从交互设备的角色加入堆叠系统，并打开业务接口）
```
