# 隔离端口组
```
作用：
    实现交换机端口隔离（仅在本交换设备的端口生效）
    同组隔离，不同组互访

补充：（隔离端口组可以配合 Super Vlan 共同使用）
    
    interface G0/0/X
	port-isolate enable group 1				
    // 把 G0/0/X 接口划入隔离端口组（1）中

	interface G0/0/Y
	port-isolate enable group 1				
    // 把 G0/0/Y 接口划入隔离端口组（1）中

配置完成后 G0/0/X 和 G0/0/Y 端口无法实现二层互访，二层隔离（无论是否相同 VLAN）

扩展：（系统配置视图） port-isolate mode all		// 开启隔离端口组模式为 ALL（二层和三层同时隔离）

二层隔离：
    - 相同 VLAN 的设备无法互访，
    - 不同 VLAN 的设备可以通过 VLANIF 实现互访
	
三层隔离：
    - 相同 VLAN 或 不同 VLAN 的设备均无法互访
    （无法通过 VLANIF 实现互访）

补充：
    隔离端口组
    （仅针对物理接口生效 “包括物理接口中的子接口”   
        - 不影响 PC 访问 VLANIF 网关，
        - 但影响 PC 间的通信）

补充：
    单向隔离
	
        interface G0/0/3
 	    am isolate G0/0/1				
        // G0/0/3 端口可以访问 G0/0/1 端口，反之禁止（单向隔离）
```
