## 无状态设计
![1721181783214](image/RESTful/1721181783214.png)
```
状态化请求：
    服务器端一般都要保存请求的相关信息，每个请求可以默认地使用以前的请求信息。

无状态请求：
    服务器端的处理结果必须全部来自于一次请求所携带的信息。
```
