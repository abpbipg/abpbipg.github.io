# 一、SDN

## 	三大特征
### 1、集中控制：通过统一平台对设备进行纳管
```    
    设备纳管后，通过平台来进行统一配置，管理和运维（把对单个设备的部署意图，交给平台完成）
```

### 2、转控分离：把控制平面和转发平面分离，设备只需要关注数据平面即可（知道如何转发数据包即可）
```
	控制信息由平台完成（如：路由计算、路径规划等）
    例如：SRv6（由控制器完成路径编排，并且把 SRv6 policy 下发到设备上，设备根据 SRH 里面的 Segment list 进行转发）
```

### 3、开放端口：开放南向和北向端口
```
    南向端口：对接设备（NETCONF、SNMP 等）
                用于对设备进行配置和管理，统一的端口可以对不同厂商和异构的设备进行纳管

    北向端口：主用用于对接云平台和第三方应用（如：网络管理软件收集，流量和设备信息，提供第三方的驱动包）
```

# 二、简单的网络运维
```
	为了减少管理员的配置压力，重复性的命令可以通过基础的代码完成（如：SSH（CLI）方式）
	复杂代码及功能可以基于 NETCONF（YANG）来完成
```

# 三、SSH
```
	安全外壳协议，用于在 TCP/IP 网络中增加管理交互的安全性
	如：telnet、ftp 都可以通过 SSH 来保障安全性（stelnet、sftp）


	SSH 协议由三个组件构成：SSH 传输层协议，SSH 用户认证协议，SSH 连接协议
		1、SSH 连接协议：通过 TCP 建立连接，端口号为：22
			SSH 连接协议将加密的会话连接多路复用成若干个逻辑通道
			它提供了 ① 交互式登录会话、② 远程执行命令、③ TCP/IP连接等，所有通道都复用一个会话连接

		2、SSH 传输层协议：用于交密钥交换算法、公钥算法、对称加密算法、消息认证算法等（密钥生成和算法协商）

		3、SSH 用户认证协议：提供用户接入时的身份认证
			SSH用户认证协议提供两种认证方法：口令认证和公钥认证
			① 口令认证：客户端通过用户名和密码登录到服务器，完成用户认证
			② 公钥认证：服务器通过公钥解密客户端的数字签名，完成用户认证
```

## 工作过程
```
（SSH 传输层协议）
1、建立 TCP 连接（确保 IP 地址可达，端口可达（22））
2、协商版本参数（目前使用 SSH 2.0 版本，SSH 1.0 需要开启兼容才能协商，推荐使用 2.0 版本，安全性高和支持的算法更多）
3、算法协商阶段（密钥交换算法、对称加密算法、消息认证算法，公钥算法）必须每种算法都匹配成功的选项才能进入下一阶段
4、密钥交换阶段：
		① 协商质数（p和g）客户机和服务器双方生成私钥和公钥，并且把公钥发送给对方
		② 通过本地私钥加对端的公钥生成会话密钥
		③ （如果是 password 模式）后续的用户名和密码信息，都通过会话密钥进行加密和解密，验证用户身份
		④ 如果验证成功，则后续交互命令行信息，也会使用会话密钥进行对称加密

（用户认证阶段）
口令认证：客户机通过会话密钥把口令信息加密后发送给对方（用户名和密码）
数字签名：本地通过公钥、公钥算法、用户名、会话 ID 等参数，使用私钥加密生成。
		 （服务器验证数字签名，成功接入接入）

（会话交互阶段）
使用传输协议生成的会话密钥进行对称加密，交互命令行和数据信息

```

# SSH 配置命令（口令认证）
```
服务器配置
	1、进入 AAA 创建账户
		local-user python password cipher Huawei@123			// 创建账户信息（用户名：python，密码：Huawei@123）
 		local-user python privilege level 3						// 用户等级必须 3 及以上
 		local-user python service-type ssh					// 指定服务类型为 ssh（包含：stelnet、sftp、snetconf）

	2、系统配置视图，开启服务及指定用户
		stelnet server enable 								// 开启 Stelnet 服务
		ssh user python service-type stelnet					// 指定 python 用户，用于 stelnet 服务
		ssh user python authentication-type password			// 指定认证类型为：password（口令认证）

	3、指定 AAA 用户登录，且接入协议为 SSH
		user-interface vty 0 4								// 进入 VTY 0 4 信道组合
 		authentication-mode aaa							// 指定认证模式为 AAA
 		protocol inbound ssh								// 指定接入的协议为 SSH（默认为：telnet）

	（确保网络可达后，可以使用工具接入）

客户机（LSW2 模拟）
	1、全局配置
		ssh client first-time enable

	2、接入设备
	（系统配置视图）
		stelnet X.X.X.X										// X.X.X.X 为交换机 1 的 IP 地址
	
	补充：提示信息，需要敲 Y（确认接入服务器，和保存服务器发送的公钥）
```				
