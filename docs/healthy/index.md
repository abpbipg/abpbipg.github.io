  ## 1.1.2 肥胖评估 4 原则

  满足以下任意一条，即可视为肥胖（临床/健康管理口径可能略有差异）：

  1. **体重指数（BMI）**：肥胖 BMI ≥ 28 kg/m²；超重 24 ≤ BMI < 28 kg/m²。  
     `BMI = 体重(kg) / 身高(m)^2`

  2. **腰围（WC）**：男 WC ≥ 90 cm；女 WC ≥ 80 cm。  
     *测量：肚脐上方约 1cm 一周腰围。*

  3. **腰围身高比（WHtR）**：男 WHtR ≥ 0.50；女 WHtR ≥ 0.56。  
     `WHtR = 腰围 / 身高`

  4. **体脂率（PBF）**：  
     - 男：肥胖 PBF ≥ 25%；超重 18% ≤ PBF < 25%  
     - 女：肥胖 PBF ≥ 30%；超重 20% ≤ PBF < 30%  
       `PBF = 1.2×BMI + 0.23×年龄 - 5.4 - 10.8×性别(男=1, 女=0)`

  对照表：

  |        类型        |                    男                     |                  女                  |
  | :----------------: | :---------------------------------------: | :----------------------------------: |
  |  体重指数（BMI）   | 肥胖 ≥ 28 kg/m²；超重 24 ≤ BMI < 28 kg/m² |              同男性标准              |
  |     腰围（WC）     |                  ≥ 90 cm                  |               ≥ 80 cm                |
  | 腰围身高比（WHtR） |                  ≥ 0.50                   |                ≥ 0.56                |
  |   体脂率（PBF）    |    肥胖 PBF ≥ 25%；超重 18% ≤ PBF < 25    | 肥胖 PBF ≥ 30%；超重 20% ≤ PBF < 30% |

  ## 1.1.3 [代谢综合征](/healthy/科普-代谢综合征.md)

  参考：[体检必备验血项目](/healthy/体检-体检必备验血项目.md)。  
  满足以下 **≥3 项**，可考虑代谢综合征（MetS）风险升高：

  1. 血压（BP）：收缩压 ≥ 130 mmHg 和/或舒张压 ≥ 85 mmHg
  2. 甘油三酯（TG）：≥ 1.7 mmol/L
  3. 高密度脂蛋白胆固醇（HDL）：男 ≤ 1.04 mmol/L；女 ≤ 1.3 mmol/L
  4. 空腹血糖（FBG）：≥ 5.6 mmol/L
  5. 腰围（WC）：男 ≥ 90 cm；女 ≥ 80 cm  
     或：腰臀比（WHR）：男 ≥ 0.90；女 ≥ 0.85
  6. 尿酸（UA）：男 > 7.0 mg/dL 或 416 umol/L；女 > 6.0 mg/dL 或 357 umol/L

  对照表：

  |            类型            |                   男                    |            女             |
  | :------------------------: | :-------------------------------------: | :-----------------------: |
  |         血压（BP）         | 收缩压 ≥ 130 mmHg 和/或舒张压 ≥ 85 mmHg |        同男性标准         |
  | 腰围（WC）或 腰臀比（WHR） |        WC ≥ 90 cm 或 WHR ≥ 0.90         | WC ≥ 80 cm 或 WHR ≥ 0.85  |
  |       甘油三酯（TG）       |              ≥ 1.7 mmol/L               |        同男性标准         |
  |      空腹血糖（FBG）       |              ≥ 5.6 mmol/L               |        同男性标准         |
  | 高密度脂蛋白胆固醇（HDL）  |              ≤ 1.04 mmol/L              |       ≤ 1.30 mmol/L       |
  |         尿酸（UA）         |         > 7.0 mg/dL 或 416 umol         | > 6.0 mg/dL 或 357 umol/L |

  ## 1.2 长久坚持，对人生有益的事

  做到以下 5 个基本点，有研究认为可显著延长健康寿命：

  1. 不吸烟
  2. 不饮酒
  3. 健康饮食
  4. BMI 控制在 18.5 ~ 22.5（[BMI 计算器](https://cn.onlinebmicalculator.com/)）
  5. 每周锻炼 6 小时以上（有氧 + 抗阻）

  ## 1.3 增强脑力的 6 个方法

  1. 补充水分和营养
  2. 增加接触自然光线
  3. 舒缓压力
  4. 合理、适当运动
  5. 增加 [脑源性神经营养因子（BDNF）](/healthy/提升BDND的实用技巧.md)
  6. 禁食

  ## 4. 备注

  ## 4.1 [什么是专利药、原研药、仿制药](/healthy/文献资料/原研药和仿制药的区别.md)

  - **专利药**：全球最先申请并获得专利保护的药品，一般有 20 年保护期，其他企业不得仿制。  
  - **原研药**：专利期结束后，由原生产商继续生产的药品。  
  - **仿制药**：专利期结束后，其他企业复制主要分子结构生产的药品（工艺等可能不同，不良反应差异也可能存在）。

  补充说明：原研药研发周期长、成本高，因此一般价格更高；仿制药研发成本低，价格相对更低，可提升可获得性。

  ## 4.2 [PICC 维护相关](/healthy/PICC置管后的家庭维护（家庭版）.pdf)

  1. PICC 维护：每 7 天一次（按医院要求执行）
  2. 并非所有医院都可维护，建议提前确认
  3. 部分医院不允许自带维护包（需遵循院方规定）

  ## 4.3 [借白片或者切片的流程](/healthy/病理分析-病理借片分清楚蜡块白片和切片.pdf)

  1. 需要借片的医院开具借片单
  2. 借片单明确：数量、厚度、是否挂胶、是否着色、是否烤片
  3. 切片类型：病理切片、免疫组化切片、白片、蜡块
